This folder contains time series data of cooking burners monitored using iButton temperature sensors, and open/close status of external (mostly patio) doors monitored with state sensors. There is one csv file for each of the 70 homes. The following column headers are used. Files for each home has a different number of columns depending on available data that was monitored.PARAMETER---------IBU = iButton temperature data logger (degree C)STN = State data logger measuring % time when door is openLOCATION--------[ for IBU ]Below are the four most commonly monitored cooktop burners:CLB = Left-back cooktop burnerCLF = Left-front cooktop burnerCRB = Right-back cooktop burnerCRF = Right-front cooktop burnerCCB = Center-back cooktop burnerThe leftmost "C" indicates cooktop. The middle letter (L / R / C) indicates left, right, or center of the cooktop. The rightmost letter (B / F / C) indicates back, front, or center of the cooktop. Other combinations of the three letters are used to represent positioning of the iButton on the cooktop. Other iButton data include:OVN = Oven, if only one oven is monitoredOVN1, OVN2 = If more than one oven is monitoredGDL = GriddleTOA = Toaster ovenFIR = FireplaceHome 015 had additional iButton placed near cooktop burners, as indicated by "_SUP" in column header.
Home 109 had two kitchens. iButton placed on cooktop of the 2nd kitchen in a side, closed room is indicated by "_KIT2" in column header. [ for STN ]DGH = Garage to house door, if only one door is monitoredDGH1, DGH2 = If more than one door is monitoredDPT = Patio door to outside, if only one door is monitoredDPT1 ... DPT4 = If more than one door is monitoredDFR = House front doorATTIC = Attic hatch door Home 041 monitored attic hatch door because work (PV installation) was being done that required attic access.
